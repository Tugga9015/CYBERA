# 🛡️ CYBERA — Cybersecurity Made Simple

**Making cybersecurity easier to understand and more accessible to everyone.**

CYBERA is an early-stage cybersecurity project being developed under **AAT Tech Solutions**. Its mission is to help everyday people understand potential digital threats through simple, accessible cybersecurity tools and guidance.

> 🚧 CYBERA is currently under development. Features and capabilities will expand as development progresses.

---

## 🎯 Our Mission

To make cybersecurity easier to understand and more accessible to everyone, regardless of their technical knowledge.

CYBERA aims to help people recognize suspicious messages, become more aware of online threats, and develop safer digital habits.

## ✨ Features

### ✅ Currently Implemented

- 🔍 Basic suspicious-message analysis.
- 🚩 Detection of selected scam-related warning phrases.
- 📊 Simple risk assessments based on detected warning signs.
- 💡 Explanations of potential concerns identified in messages.
- 🔌 REST API built with Node.js and Express.js.
- ❤️ API health-check endpoint.

### 🚧 Planned Features

- 🔎 Expanded suspicious-message detection.
- 🌐 Suspicious URL analysis.
- 🤖 CYBERA AI for beginner-friendly security guidance.
- 📚 Cybersecurity learning centre.
- 🎙️ Voice accessibility and simplified guidance.
- 📱 Future Android application.
- 🔗 CYBERA SHARE for analyzing content users deliberately share.

*Planned features are not yet available.*

---

## 💻 Technologies

The project currently uses:

- **JavaScript** — Programming language.
- **Node.js** — JavaScript runtime.
- **Express.js** — Backend framework.
- **Git and GitHub** — Version control and source code management.
- **Thunder Client** — API testing.

Additional technologies may be introduced as the project evolves.
